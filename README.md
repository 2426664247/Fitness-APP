# FitDay

FitDay 是一个轻量 Android 健身训练 App，训练计划不绑定星期几。

## 内置训练模板

- 胸 + 手臂
- 背 + 肩
- 腿部

## 自定义计划

- 从零创建训练计划
- 从内置模板复制后修改
- 添加 / 删除动作
- 调整动作顺序
- 修改每个动作的组数、次数和休息时间
- 自定义计划本地持久化

## 训练功能

- GIF 动作演示
- 动作要领与常见错误
- 每组完成记录
- 自动组间休息计时
- 训练完成度
- 历史训练记录
- 多计划独立进度

## Android

- Android WebView 壳
- minSdk 24
- targetSdk / compileSdk 35
- GitHub Actions 自动构建 Debug APK

动作 GIF 来自开源 Exercise Library。
